## 学习路径

1. 从 **Python 基础** 与 **竞赛基本功** 开始，熟悉常用语法、输入输出和复杂度分析。
2. 按 **数据结构 → 基础算法 → 搜索 / 数学 / 图论** 的顺序建立解题框架。
3. 对照每章的题目练习，并在 [题解目录](https://github.com/w3903771/algorithm/tree/main/solutions){ target="_blank" } 查看 Python 实现。
