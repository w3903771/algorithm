## 怎么用这本书

三种读法，按你现在的状态挑一种：

- **零基础 / 想系统过一遍**：从 **Python 基础** 顺序读到 **动态规划**，每章末尾的例题当场做掉。章节底部有「上一章 / 下一章」，一路点下去就行。
- **只想补某个知识点**：在下面的章节盘里找章号，或者用右上角搜索。章节之间的前置依赖写在每章开头的引言里。
- **在刷题，卡在某道题上**：去 [题解](solutions/index.md) 按题号找，每页都写了「这题考什么、数据规模、坑在哪」，再往下是能直接跑的完整代码。

!!! tip "关于 Python 的常数"

    正文默认用 CPython 的写法。少数几道题 CPython 物理上过不去，题解页会标出 `pypy3`，
    原因写在那一页的「为什么必须 PyPy3」里。
